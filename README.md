# سبورتي

سبورة بيضاء تفاعلية باللغة العربية (RTL بالكامل)، مبنية بـ Next.js وFabric.js.

## المرحلة الحالية (كل المراحل — المشروع مكتمل)

- محرك رسم كامل: قلم حر، فرشاة رش، تظليل، ممحاة، نصوص، ملاحظات لاصقة
- 6 أشكال هندسية جاهزة (مستطيل، دائرة، مثلث، خط، سهم، نجمة)
- تحكم في اللون (14 لون جاهز + منتقي حر)، الحجم، والشفافية
- نظام طبقات كامل: إخفاء/إظهار، قفل، إعادة تسمية، تغيير الترتيب، حذف
- استيراد صور، تصدير PNG بدقة عالية
- تراجع/إعادة حتى 40 خطوة (Ctrl+Z / Ctrl+Y)
- صفحة رئيسية لإدارة اللوحات: إنشاء، إعادة تسمية، نسخ، حذف
- حفظ تلقائي مستمر بالكامل على المتصفح (localStorage)
- **استيراد ملفات PDF متعددة الصفحات**: اللوحة تاخد حجم كل صفحة بالظبط
- **الرسم والكتابة فوق أي صفحة PDF** مع الحفاظ على كل صفحة كوحدة مستقلة
- **تصفح الصفحات** عبر شريط صور مصغّرة أسفل اللوحة
- **تصدير PDF جديد** يحتوي على كل التعديلات بنفس ترتيب الصفحات الأصلي
- **الملاحظات الصوتية**: تسجيل مباشر من المايكروفون بضغط تلقائي (~نصف ميجابايت للدقيقة عبر Opus 64kbps)
- وضع علامة 🎙️ في أي مكان على اللوحة، وتشغيلها بنقرة مزدوجة عليها
- تخزين الملاحظات الصوتية محليًا بالكامل عبر IndexedDB (بدون أي اتصال سحابي)
- قائمة خاصة لإدارة كل الملاحظات الصوتية على اللوحة: تشغيل، إعادة تسجيل، حذف
- **5 قوالب جاهزة للخرائط الذهنية وتنظيم الأفكار**: خريطة ذهنية كلاسيكية، مخطط تنظيمي هرمي، خط زمني، أسباب ونتائج (عظم السمكة)، مخطط تدفق
- كل عنصر في القالب (عقدة، خط ربط) منفصل وقابل للتحريك والتعديل الكامل بعد الإدراج
- **تصدير فيديو الشرح**:
  - تسجيل مباشر للوحة مع دمج صوت المايكروفون
  - إعادة تشغيل تلقائي لخطوات الجلسة الحالية وتسجيلها كفيديو (×1 / ×2 / ×4)
  - حد أقصى 10 دقائق للفيديو، بمعدل 30 إطارًا في الثانية
  - الصيغة تُختار تلقائيًا حسب المتصفح: WebM في كروم وإيدج، MP4 في سفاري
  - معاينة الفيديو قبل الحفظ مع إمكانية التجاهل وإعادة المحاولة
- **نظام الحسابات والمزامنة السحابية (اختياري)**:
  - تسجيل دخول بالبريد الإلكتروني/كلمة المرور أو عبر حساب Google
  - نسخة احتياطية من كل لوحاتك على قاعدة بيانات Supabase
  - استرجاع اللوحات تلقائيًا عند تسجيل الدخول من أي جهاز آخر
  - حماية كاملة عبر Row Level Security: كل مستخدم يرى لوحاته فقط
  - الموقع يعمل بشكل طبيعي وكامل محليًا حتى بدون تفعيل هذه الميزة

## نظام الطبقات

- كل طبقة عندها أيقونة توضّح نوعها (قلم، شكل، نص، ملاحظة صوتية...)
- الضغط على طبقة في القائمة يحدّدها على اللوحة، والعكس: تحديد عنصر على اللوحة يلوّن طبقته في القائمة
- كل قالب من قوالب الخرائط الذهنية بيتحط كطبقة واحدة فقط (مش عشرات العناصر منفصلة)، وتقدر تكبّر/تصغّر/تحرّك القالب كله ككتلة واحدة
- انقر مرتين على أي عنصر نصي — حتى لو جوه ملاحظة لاصقة أو عقدة في قالب — عشان تكتب فيه مباشرة

## تجميع الطبقات وترتيبها

- حدّد أكتر من عنصر على اللوحة (بالسحب حول العناصر) واضغط "تجميع" في اللوحة اللي بتظهر فوق — تتحول لطبقة واحدة تتحرك وتتكبّر كوحدة
- المجموعات اللي عملتها بنفسك بس تقدر تفكّها ("فك التجميع") — الملاحظات اللاصقة وعلامات الصوت والقوالب الجاهزة محمية من الفك الخطأ
- اسحب أي طبقة في قائمة الطبقات لأعلى أو لأسفل لإعادة ترتيبها مباشرة، أو استخدم أسهم لأعلى/لأسفل كما كان

## تجربة لوحة احترافية

- تكبير/تصغير حقيقي (Ctrl/Cmd + عجلة الماوس، أو أزرار +/- أسفل يسار اللوحة)، وتحريك اللوحة بعجلة الماوس العادية
- شبكة نقاط خفيفة في الخلفية للإحساس بالمساحة، تختفي تلقائيًا في وضع PDF
- تحديد العناصر بلون العلامة بدل الأزرق الافتراضي، بمقابض دائرية أنيقة
- مؤشر الماوس يتغيّر حسب الأداة المختارة (قلم/تقاطع، ممحاة، نص، تحديد)
- حالة فارغة أنيقة تظهر تلقائيًا عند فتح لوحة جديدة وتختفي مع أول رسمة

## التصميم والهوية

- ألوان فاتحة وهادئة: ورقي دافئ (`#faf9f5`)، حبر داكن للنصوص، وأخضر مائل للزُّمردي (`#1f6f63`) كلون العلامة. كلها معرّفة كمتغيرات في `app/globals.css`
- مجموعة أيقونات مرسومة يدويًا بأسلوب موحّد (خط واحد بسماكة ثابتة وأطراف مستديرة) في `features/shared/icons/Icon.tsx`، بدون أي مكتبة أيقونات جاهزة ولا إيموجي
- لوحة الرسم: شريط أدوات عائم في المنتصف، ولوحة خصائص (لون/حجم/شفافية) تظهر فقط مع الأدوات التي تحتاجها، وعنقود إجراءات في الزاوية، وطبقات في بطاقة عائمة قابلة للإخفاء
- الداشبورد: شريط جانبي، بحث، وشبكة لوحات؛ ويتحول إلى شريط علوي على الجوال

## إعداد الحسابات والمزامنة (اختياري)

الموقع يعمل بالكامل محليًا بدون أي إعداد. لتفعيل تسجيل الدخول والمزامنة السحابية:

1. أنشئ مشروعًا مجانيًا على [supabase.com](https://supabase.com)
2. افتح **SQL Editor** في لوحة تحكم المشروع، وشغّل محتوى الملف
   `supabase/schema.sql` كاملًا (ينشئ جدول اللوحات وسياسات الحماية)
3. لتفعيل تسجيل الدخول بحساب Google: من **Authentication → Providers**
   فعّل Google وأدخل بيانات OAuth الخاصة بك
4. انسخ `.env.example` باسم `.env.local` وضع فيه:
   - `NEXT_PUBLIC_SUPABASE_URL` (من Project Settings → API)
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` (من نفس الصفحة)
5. أعد تشغيل `npm run dev` أو ابنِ المشروع من جديد

بدون هذه الخطوات، زر "تسجيل الدخول" لا يظهر أصلًا والموقع يعمل محليًا فقط —
لا حاجة لأي إعداد إذا كنت لا تريد هذه الميزة.

## ملاحظات معروفة (شفافية كاملة)

- **PDF**: التراجع/الإعادة (Ctrl+Z) يتصفّر عند الانتقال بين صفحات PDF — يعمل داخل الصفحة الحالية فقط
- **القوالب**: خطوط الربط بين العقد خطوط بسيطة بدون رأس سهم، ولا تتحرك تلقائيًا مع تحريك العقدة
- **الفيديو**: "إعادة التشغيل التلقائي" تعمل على خطوات الجلسة الحالية فقط (منذ فتح اللوحة الآن)، وتُفقد عند إغلاق المتصفح؛ ودقة الفيديو = دقة اللوحة الفعلية على الشاشة وقتها، وليست 1280×720 ثابتة
- **المزامنة السحابية**: الملاحظات الصوتية (المخزّنة في IndexedDB) لا تُرفع حاليًا إلى Supabase — فقط محتوى اللوحة نفسه (الرسومات، صفحات PDF). المزامنة تتم عند تسجيل الدخول، عند الضغط على "مزامنة الآن"، وعند مغادرة لوحة أثناء تسجيل الدخول — وليست فورية أثناء الرسم
- **الخط**: تستخدم النسخة خط النظام الافتراضي بدل Cairo من Google Fonts، لأن بيئة البناء هنا بدون إنترنت خارجي؛ يمكن تفعيل `next/font/google` بسهولة بعد الرفع على Vercel

## المراحل القادمة

لا توجد مراحل متبقية من الخطة الأصلية. كل الميزات المذكورة في الفكرة الأولى
مبنية وشغالة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

يفتح المشروع على `http://localhost:3000`.

## البناء للإنتاج

```bash
npm run build
npm start
```

## بنية المشروع

```
app/                      صفحات Next.js (الرئيسية + محرر اللوحة)
features/boards/          إدارة اللوحات (تخزين، قائمة، بطاقات)
features/whiteboard/      محرك الرسم (Toolbar, LayersPanel, Canvas Engine)
```
